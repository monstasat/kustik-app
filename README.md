# Кустик PWA

Мобильное веб-приложение для дневника Кустика.

## GitHub Pages
1. Создайте публичный репозиторий `kustik-app`.
2. Загрузите содержимое этой папки в корень репозитория.
3. В GitHub откройте Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. После публикации сайт будет доступен примерно по адресу:
   `https://<username>.github.io/kustik-app/`

На iPhone откройте сайт в Safari → Поделиться → На экран «Домой».
